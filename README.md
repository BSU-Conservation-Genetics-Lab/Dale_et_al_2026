# Assessments of TLR Diversity 

The scripts here provide were used to assess quality, trim raw sequences, perform variant calling, filtering, convert LRR regions from AA to genomic position, subset VCFs for regions of interest (CDS and LRR), count and average biallelic SNPs, SNP annotation, and generate gene/ region specific haplotype consensus files. This code is associated with Dale et al. (In Prep) for Molecular Ecology Resources (submitted __), and the Master's of Raptor Biology thesis by Sage Dale - Using Comparative Genomics to Characterize Immune Genes Between the Holarctic Gyrfalcon and the Globally Distributed Peregrine Falcon (2026) - at Boise State University, Conservation Genetics Lab (PI Galla).
